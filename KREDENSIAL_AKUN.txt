4. ALUR PENDAFTARAN BARU, PASSWORD SEKALI LIHAT, & NOTIFIKASI WHATSAPP
--------------------------------------------------------------------------------
Alur Lengkap:
  1. Calon mitra / wisatawan membuka menu "Mitra" -> tab "Ajukan Kemitraan Baru".
  2. Mengisi formulir dengan:
     - Nomor WhatsApp Pemohon : (Misal: 081345678910) -> INI AKAN JADI ID LOGIN
     - Password Diinginkan    : (Kombinasi huruf & angka, misal: Borneo2026)
     - Nama Usaha & Fasilitas
  3. Setelah dikirim, sistem memunculkan dialog konfirmasi yang merangkum
     Nomor WhatsApp & Password tersebut agar dicatat oleh pendaftar.
  4. Petugas masuk ke URL rahasia /login:
     - Di kartu antrean, password disembunyikan (••••••••) demi privasi.
     - Petugas menekan tombol "ACC & Buat Akun".
     - Akun otomatis aktif seketika di server!
  5. POPUP KREDENSIAL (SEKALI LIHAT):
     - Menampilkan rincian ID Login & Password mitra yang baru diaktifkan.
     - Menyediakan tombol hijau "Kirim Kredensial via WhatsApp":
       Sekali klik, WhatsApp akan terbuka otomatis dengan nomor pemohon dan pesan
       resmi berisi rincian:
       * Tautan Masuk (/mitra)
       * ID Login (No. WhatsApp)
       * Password Keamanan
     - Tersedia juga tombol "Salin Pesan" untuk copy-paste instan.
